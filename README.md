# School Admission System

First-come-first-served school admission system: independently seat-limited classes, temporary
seat holds with expiry, simulated payment confirmation, and a React UI that shows live availability.

Stack: .NET 8 (ASP.NET Core, EF Core, Npgsql), PostgreSQL, React 18 with TypeScript and Vite, Docker Compose.

Setup, architecture and test instructions are added as the implementation lands.
